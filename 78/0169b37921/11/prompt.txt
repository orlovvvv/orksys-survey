# Protected Pages Header Design

## Context

The current header for protected pages (`apps/web/src/components/header.tsx`) is a simple horizontal navigation that lacks:
- Mobile responsiveness (no hamburger menu)
- Modern design patterns
- Compound component flexibility
- Avatar in user menu
- Breadcrumb support

This plan creates a modern, flexible header component using compound component patterns, shadcn/ui components, and React 19 best practices.

---

## Component Structure

```
apps/web/src/components/app-header/
├── index.ts                    # Public exports
├── context.tsx                 # Header context for state sharing
├── app-header.tsx              # Root header component
├── header-nav.tsx              # Desktop navigation
├── mobile-menu.tsx             # Mobile sheet menu
├── breadcrumb.tsx              # Breadcrumb component
└── types.ts                    # Shared types
```

---

## API Design

```tsx
// Simplified API (recommended)
<AppHeader
  navItems={navItems}
  showOrgSwitcher
  showThemeToggle
  showUserMenu
  breadcrumbs={[{ label: "Surveys" }]}
/>

// Compound API (for flexibility)
<AppHeader>
  <AppHeader.Logo />
  <AppHeader.Nav />
  <AppHeader.Actions>
    <AppHeader.OrgSwitcher />
    <AppHeader.ThemeToggle />
    <AppHeader.UserMenu />
  </AppHeader.Actions>
</AppHeader>
```

---

## Key Features

1. **Desktop Layout**: Logo + centered nav + right actions (org switcher, theme, user menu)
2. **Mobile Layout**: Hamburger menu triggers Sheet with navigation
3. **Active state**: Visual indicator for current page
4. **Breadcrumbs**: Optional breadcrumb support
5. **Avatar**: User initials/image in user menu dropdown

## Implementation Steps

### Step 1: Create types.ts
```tsx
export interface NavItem {
  href: string;
  label: string;
  icon?: ReactNode;
  badge?: string | number;
  disabled?: boolean;
}

export interface AppHeaderContextValue {
  navItems: NavItem[];
  currentPath: string;
  mobileMenuOpen: boolean;
  setMobileMenuOpen: (open: boolean) => void;
}

export interface AppHeaderProps {
  children?: ReactNode;
  className?: string;
  navItems?: NavItem[];
  showOrgSwitcher?: boolean;
  showThemeToggle?: boolean;
  showUserMenu?: boolean;
  breadcrumbs?: Array<{ label: string; href?: string }>;
  sticky?: boolean;
  border?: "none" | "bottom" | "full";
}
```

### Step 2: Create context.tsx
- Use React 19 `use()` instead of `useContext()`
- Provide: `navItems`, `currentPath`, `mobileMenuOpen`, `setMobileMenuOpen`
- Use `usePathname()` for current path tracking

### Step 3: Create app-header.tsx
- Root component with provider wrapper
- Desktop: Logo (left) + Nav (center) + Actions (right)
- Mobile: Logo + Hamburger button (left) + Actions (right)
- Integrate existing: `OrganizationSwitcher`, `ModeToggle`, `UserMenu`

### Step 4: Create header-nav.tsx
- Simple tab-like navigation using `Button` with `variant="ghost"`
- Active state: `bg-accent text-accent-foreground` + bottom underline
- Hidden on mobile (`hidden md:flex`)

### Step 5: Create mobile-menu.tsx
- Use `Sheet` component with `side="left"`
- Navigation links with active states
- Footer with Settings and Sign Out

### Step 6: Create breadcrumb.tsx
- Home icon + ChevronRight separators
- Last item is non-clickable
- Hidden on mobile

### Step 7: Update user-menu.tsx
- Add `Avatar` component with user image or initials
- Improve dropdown with user info header

### Step 8: Update (app)/layout.tsx
```tsx
import { AppHeader } from "@/components/app-header";

const navItems = [
  { href: "/dashboard", label: "Dashboard" },
  { href: "/surveys", label: "Surveys" },
  { href: "/todos", label: "Todos" },
];

export default function AppLayout({ children }) {
  return (
    <div className="grid h-svh grid-rows-[auto_1fr]">
      <AppHeader navItems={navItems} showOrgSwitcher showThemeToggle showUserMenu />
      {children}
    </div>
  );
}
```

## Styling Approach

- Uses semantic CSS variables: `bg-card`, `text-foreground`, `border-border`
- Active states: `bg-accent text-accent-foreground`
- Responsive: `hidden md:flex` for desktop nav, `md:hidden` for mobile toggle
- Header height: `h-14` (56px)
- Spacing: `gap-2`, `px-4`

---

## Accessibility

- `aria-label` on mobile menu toggle
- `aria-current="page"` on active nav items
- Sheet provides focus trap
- Keyboard navigable
