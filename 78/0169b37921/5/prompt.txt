# Account Management & User Settings

## Context

Implement a comprehensive account management experience allowing users to fully manage their profile, security settings, subscription, and account. This leverages Better Auth's full capabilities including email verification, password management, two-factor authentication, session management, and Polar subscription integration.

---

## Server-side Requirements

### 1. Enable Better Auth Plugins

**File:** `packages/auth/src/index.ts`

```typescript
import { emailVerification } from "better-auth/plugins";
import { resend } from "@trigger.dev/email/resend"; // or direct Resend SDK

export const auth = betterAuth({
  emailAndPassword: {
    enabled: true,
    requireEmailVerification: false,
  },
  plugins: [
    organization({...}),
    emailVerification({
      sendVerificationEmail: async ({ user, url }) => {
        await resend.emails.send({
          from: env.EMAIL_FROM,
          to: user.email,
          subject: "Verify your email address",
          html: `Click <a href="${url}">here</a> to verify your email.`,
        });
      },
      sendResetPassword: async ({ user, url }) => {
        await resend.emails.send({
          from: env.EMAIL_FROM,
          to: user.email,
          subject: "Reset your password",
          html: `Click <a href="${url}">here</a> to reset your password.`,
        });
      },
    }),
    polar({...}),
    nextCookies(),
    expo(),
  ],
});
```

### 2. Update Auth Client

**File:** `apps/web/src/lib/auth-client.ts`

No changes needed - `emailVerification` plugin works without client-side additions.

### 3. Environment Variables

Add to `packages/env/src/server.ts`:
```typescript
RESEND_API_KEY: z.string(),
EMAIL_FROM: z.string(), // e.g., "noreply@yourdomain.com"
```

> **Note:** 2FA is deferred to a future implementation. Focus is on profile, password, sessions, and subscription.

## Hook Patterns

Following existing pattern from `components/organization/hooks/`:

```typescript
// use-sessions.ts
export function useSessions() {
  const queryClient = useQueryClient();

  const query = useQuery({
    queryKey: ["auth", "sessions"],
    queryFn: async () => {
      const response = await authClient.session.list();
      return response.data ?? [];
    },
  });

  const revokeMutation = useMutation({
    mutationFn: (id: string) => authClient.session.revoke({ id }),
    onSuccess: () => queryClient.invalidateQueries({ queryKey: ["auth", "sessions"] }),
  });

  return {
    sessions: query.data ?? [],
    isLoading: query.isLoading,
    revokeSession: revokeMutation.mutate,
    isRevoking: revokeMutation.isPending,
  };
}
```
