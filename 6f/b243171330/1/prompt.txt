# Landing Page Composition Refactoring

## Context

The landing page has inconsistent wrapper patterns, redundant nesting, and missing responsive breakpoints. Following Vercel's composition patterns, we need to:
1. Remove excessive wrapper divs that interfere with positioning
2. Standardize section padding/sizing with consistent responsive breakpoints
3. Ensure proper tablet/mobile responsiveness
4. Use composition patterns (compound components) for reusable section primitives

---

## Current Issues Identified

### 1. Redundant Wrapper Patterns
- Most sections have 2-3 nested divs that could be flattened
- Example: `<section><div class="mx-auto max-w-7xl"><div>content</div></div></section>`
- Footer has external `pb-12` wrapper + internal `py-24` = redundant spacing

### 2. Inconsistent Spacing
| Component | Current | Issue |
|-----------|---------|-------|
| HeroSection | `px-6` only | No tablet/desktop increase |
| BentoFeatures | `px-6` only | No responsive scale |
| CoreFeatures | `px-6` only | No responsive scale |
| Testimonials | `px-6 md:px-12 lg:px-24` | Good pattern |
| Pricing | `px-6 md:px-12 lg:px-24` | Good pattern |
| CTASection | `px-6 md:px-12 lg:px-24` | Good pattern |
| Footer | `px-6 md:px-12 lg:px-24` | Good pattern |

### 3. Missing Responsive Breakpoints
| Component | Issues |
|-----------|--------|
| SurveyMockup | Fixed `h-[750px]`, fixed sidebar widths, no mobile collapse |
| HeroSection | Missing `lg:` breakpoint for typography |
| CoreFeatures | Grid jumps from 1 to 3 cols, missing `md:` breakpoint |

### 4. Container Strategy Inconsistency
- Some components have external wrapper in `page.tsx`, some internal
- SurveyMockup and SocialProof wrapped together in page.tsx with `max-w-7xl px-6`
- Other sections have internal `max-w-7xl`

## Implementation Plan

### Phase 1: Create Section Primitives

**File:** `apps/web/src/components/landing/ui/section.tsx`

Create a compound Section component following composition patterns:

```tsx
// Section primitive with consistent spacing
const Section = ({
  as: Component = "section",
  size = "default", // "default" | "narrow" | "wide"
  background = "transparent", // "transparent" | "muted" | "dark"
  className,
  children,
}) => {
  const widths = {
    narrow: "max-w-5xl",
    default: "max-w-7xl",
    wide: "max-w-full",
  }
  return (
    <Component className={cn(
      "px-6 py-24 md:px-12 lg:px-24",
      backgrounds[background],
      className
    )}>
      <div className={cn("mx-auto", widths[size])}>
        {children}
      </div>
    </Component>
  )
}
```

### Phase 2: Create SectionHeader Component

**File:** `apps/web/src/components/landing/ui/section-header.tsx`

Extract the repeated header pattern from BentoFeatures/CoreFeatures:

```tsx
const SectionHeader = ({
  label,
  title,
  description,
  action,
  align = "left", // "left" | "center"
}) => {
  return (
    <div className="mb-12 flex flex-col">
      {label && (
        <div className="flex items-center gap-2 pb-5">
          <span className="h-px w-8 bg-primary" />
          <span className="text-xs uppercase tracking-widest text-primary font-bold">
            {label}
          </span>
          {action && <div className="ml-auto">{action}</div>}
        </div>
      )}
      <div className="h-px w-full bg-neutral-200 mb-8" />
      <div className={cn(
        "flex flex-col gap-8 lg:flex-row lg:items-start lg:gap-16",
        align === "center" && "text-center items-center"
      )}>
        <h2 className="text-3xl md:text-4xl lg:text-5xl font-display tracking-tight text-neutral-900">
          {title}
        </h2>
        {description && (
          <p className="text-base text-neutral-600 leading-relaxed lg:max-w-sm lg:pt-2">
            {description}
          </p>
        )}
      </div>
    </div>
  )
}
```

### Phase 3: Flatten Component Wrappers

For each component, remove redundant nesting:

#### 3.1 `hero-section.tsx`
**Before:**
```tsx

  <div className="mx-auto max-w-7xl px-6 text-center">
    {/* content */}
  </div>
</section>
```

**After:**
```tsx
<section className="mesh-gradient relative overflow-hidden px-6 py-24 md:px-12 lg:px-24 text-center">
  <div className="mx-auto max-w-7xl">
    {/* content */}
  </div>

```

#### 3.2 `bento-features.tsx`


```tsx

  {/* Remove z-10 wrapper - not needed */}
```


#### 3.4 `testimonials.tsx`, `pricing.tsx`, `cta-section.tsx`, `footer.tsx`

### Phase 4: Standardize Page Composition

**File:** `apps/web/src/app/page.tsx`

**Before:**

```tsx
    <SocialProof />
```

```tsx
  <BentoFeatures />
  {/* ... */}
  <Footer />
</main>
```

### Phase 5: Add Missing Responsive Breakpoints

#### 5.1 `survey-mockup.tsx` - Mobile Collapse
- Collapse sidebars on mobile (< lg)
- Reduce fixed height on mobile
- Stack header buttons on mobile

**Key changes:**
```tsx
// Height: fixed 750px → responsive
className="flex min-h-[500px] lg:h-[750px] flex-col"

// Left sidebar: hidden on mobile, shown on lg
className="hidden lg:flex h-full w-64"

// Right sidebar: hidden on mobile, shown on lg
className="hidden lg:flex h-full w-72"

// Header buttons: stack on mobile
className="flex flex-col sm:flex-row items-center gap-3"
```

#### 5.2 `hero-section.tsx` - Add lg Breakpoint
```tsx
// Typography scale
"text-4xl sm:text-5xl md:text-6xl lg:text-7xl"

// Input + button layout
"flex flex-col sm:flex-row gap-4 w-full max-w-2xl"
```

#### 5.3 `core-features.tsx` - Add md Breakpoint for Grid
```tsx
// Grid: 1 → 2 → 3 columns
"grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6"
```
