# Landing Page Implementation Plan

## Context

The user wants to recreate a polished SaaS landing page for "Handshake" (a survey platform) based on a design file at `design/landing.html`. The current web app uses shadcn/ui with "base-lyra" style and neutral theme. The user wants to:

1. Initialize a fresh shadcn setup with "nova" style, zinc base color, violet accent, and inter font
2. Extract and apply this theme to the main web app
3. Reinstall/adjust all shadcn components
4. Recreate the landing page from the design file
5. **Replace all amber/orange colors with violet** (user explicitly requested violet instead of the design's coral/orange)

## Design Summary (from `design/landing.html`)

### Page Sections
1. **Navigation** - Fixed dark pill navbar with logo, nav links, and CTA button
2. **Hero** - Mesh gradient background, headline, email capture form, large survey builder mockup
3. **Social Proof** - "Trusted by" with placeholder logos
4. **Bento Feature Grid** - 4 cards (Security, Visual, Completion Rate, AI Analysis)
5. **Core Features** - 4 feature cards in bento layout (Logic, Analytics, Audience, Templates)
6. **Testimonials** - 3 testimonial cards with highlighted middle card
7. **Pricing** - 3 tiers (Personal $0, Growth $29, Business $99)
8. **CTA** - Large rounded container with dual CTAs and trust badges
9. **Footer** - Dark card with newsletter, links, social

### Color Replacements
| Original | Replacement |
|----------|-------------|
| `#FF7F50` (coral) | `violet-500` / CSS variable |
| `#FF6347` (tomato) | `violet-600` / CSS variable |
| `orange-*` classes | `violet-*` classes |

### Key Design Elements
- Large border radii: `rounded-[40px]`, `rounded-[32px]`
- Gradients: `from-violet-500 to-violet-600`
- Shadows with color: `shadow-violet-500/30`
- Mesh gradient background (radial gradients)
- Lucide icons (replacing Solar/Iconify)
- Inter font (already using Inter Variable)

## Implementation Steps

### Phase 1: Initialize shadcn with Violet Theme

**Files to modify:**
- `apps/web/components.json`
- `apps/web/src/index.css`

**Steps:**
1. Create `/tmp/shadcn-theme` directory
2. Run: `pnpm dlx shadcn@latest create` with nova/violet preset
3. Extract `components.json` and CSS variables from tmp project
4. Update `apps/web/components.json` with nova style settings
5. Update `apps/web/src/index.css` with violet theme CSS variables
6. Add mesh gradient CSS utility for hero background

### Phase 2: Reinstall shadcn Components

**Required components:**
- `button`, `card`, `input`, `label` (existing - refresh)
- `badge`, `switch`, `avatar`, `separator` (new - install)

**Steps:**
1. Run `pnpm dlx shadcn@latest add button card input label badge switch avatar separator --overwrite`
2. Verify components use the new violet theme
3. Run `pnpm check` to format/lint

### Phase 3: Set Up Route Structure

**Architecture decision:** Use route groups to separate landing from authenticated pages.

```
apps/web/src/app/
├── layout.tsx              # Root layout (providers, fonts, theme)
├── page.tsx                # Landing page (compose sections)
├── (app)/
│   ├── layout.tsx          # App layout with Header
│   ├── dashboard/page.tsx
│   └── todos/page.tsx
├── login/page.tsx          # Auth pages (no app header)
└── success/page.tsx
```

**Files to modify:**
- `apps/web/src/app/layout.tsx` - Remove Header from root
- Create `apps/web/src/app/(app)/layout.tsx` - Add Header here
- Move dashboard/todos into (app) group

### Phase 4: Create Landing Page Components

**Directory structure:**
```
apps/web/src/components/landing/

├── pricing.tsx            # 3 pricing tiers
```
