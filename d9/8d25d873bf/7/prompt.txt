# Survey Builder: Enhanced Animations and Visible Delete Button

## Context
The user wants to improve the survey builder UX with:
1. Better drop area visualization showing where items will be placed
2. Animated movement of existing items when hovering over drop positions
3. Visible delete button directly on canvas items (not hidden in a menu)

## Current Implementation
- Uses `@dnd-kit` for drag-and-drop and `framer-motion` for animations
- Drop indicator is a simple dashed border box
- Delete button is hidden in a DropdownMenu (requires two clicks)

### Task 2: Enhanced Drop Indicator

**File:** `apps/web/src/components/survey-builder/builder-canvas.tsx`

1. Enhance `DropIndicator` with animated glow effect
2. Show the question type being dragged
3. Add height animation for smooth insertion

```tsx
interface DropIndicatorProps {
  questionType?: Question["type"];
}

function DropIndicator({ questionType }: DropIndicatorProps) {
  return (
    <motion.div
      initial={{ opacity: 0, height: 0 }}
      animate={{ opacity: 1, height: "auto" }}
      exit={{ opacity: 0, height: 0 }}
      className="overflow-hidden"
    >
      <div className="relative flex items-center gap-3 rounded-xl border-2 border-violet-500 bg-violet-50 p-4">
        {/* Animated glow */}
        <motion.div
          className="absolute inset-0 rounded-xl border-2 border-violet-400"
          animate={{ opacity: [0.3, 0.7, 0.3] }}
          transition={{ duration: 1.5, repeat: Infinity }}
        />
        <Plus className="h-5 w-5 text-violet-600" />
        <span className="font-medium text-violet-700">
          Drop to add {questionTypeLabels[questionType]}
        </span>
      </div>
    </motion.div>
  );
}
```

### Task 3: Animated Item Displacement

**File:** `apps/web/src/components/survey-builder/builder-canvas.tsx`

3. Animate existing items to shift when hovering over drop position

```tsx
import { LayoutGroup } from "framer-motion";

// In render, wrap SortableContext with LayoutGroup
<LayoutGroup>
  <SortableContext items={safeQuestions.map(q => q.id)} strategy={verticalListSortingStrategy}>
    {safeQuestions.map((question, index) => {
      // Calculate if this item should shift down
      const shouldShift = isOver && activeDragItem?.type === "palette" && index >= dropIndex;

      return (
        <motion.div
          key={question.id}
          layout
          animate={{ y: shouldShift ? 80 : 0 }}
          transition={{ type: "spring", stiffness: 400, damping: 30 }}
        >
          <QuestionCard ... />
        </motion.div>
      );
    })}
  </SortableContext>
</LayoutGroup>
```
