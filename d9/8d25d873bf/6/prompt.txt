# Fix Drag-and-Drop from Palette to Canvas

## Context
The previous implementation added drag-and-drop from the question palette to the canvas, but it doesn't work. Clicking to add questions works fine, but dragging from the sidebar doesn't trigger question creation.

**Root causes identified:**
1. **Duplicate draggable IDs** - Both `QuestionTypeButton` and `QuestionTypeIconButton` use `palette-${config.type}`, creating duplicate IDs
2. **Wrong collision detection** - `closestCenter` doesn't work for cross-container dragging
3. **Creation timing** - Creating on `handleDragOver` instead of `handleDragEnd`

- `apps/web/src/components/survey-builder/index.tsx` - DndContext configuration

**Alternative:** Use `collisionDetection` with a custom array that tries `pointerWithin` first, then falls back to `closestCenter`:
```tsx
import { pointerWithin, closestCenter, CollisionDetection } from "@dnd-kit/core";

// Custom collision detection that prefers pointerWithin for palette items
const collisionDetection: CollisionDetection = (args) => {
  // First try pointerWithin for cross-container dragging
  const pointerCollisions = pointerWithin(args);
  if (pointerCollisions.length > 0) {
    return pointerCollisions;
  }
  // Fall back to closestCenter for reordering
  return closestCenter(args);
};
```
