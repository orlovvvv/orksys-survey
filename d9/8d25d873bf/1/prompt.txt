# Fix Drop Indicator: Position-Aware Placement

## Context
The previous implementation attempted to show a drop indicator between question cards, but it doesn't work because:
1. Question cards use `useSortable` (for reordering) but are NOT registered as droppable targets
2. The collision detection only returns "canvas" as the `over.id` - never individual question IDs
3. Therefore `overId` is always "canvas" and `dropIndex` always equals `questions.length`
4. The indicator never shows between cards, and insertion always happens at the end

## Root Cause Analysis
```
Palette Item → Drag → Collision Detection → over.id = "canvas" (only)
                                    ↓
                          overId = "canvas"
                                    ↓
                          dropIndex = questions.length (never a specific index)
                                    ↓
                          Indicator only shows at end
```

The issue is that `useSortable` registers items for sorting within a `SortableContext`, but it doesn't make them droppable targets for cross-container drops from the palette.

## Solution Options

### Option A: Add useDroppable to Question Cards (Chosen)
Make each question card a droppable target in addition to being sortable. This allows collision detection to return the specific question ID when hovering over it.

### Option B: Use Pointer Coordinates
Track the pointer Y position and calculate which question we're over based on bounding rects. More complex but doesn't require modifying question cards.

## Implementation (Option A)

### 1. Add Droppable to Question Cards
**File: `question-card.tsx`**

Add `useDroppable` alongside the existing `useSortable`:

```tsx
import { useDroppable } from "@dnd-kit/core";

export function QuestionCard({ question, ... }) {
  // Existing sortable setup
  const {
    attributes,
    listeners,
    setNodeRef: setSortableRef,
    transform,
    transition,
    isDragging,
  } = useSortable({ id: question.id });

  // NEW: Also make this a droppable target for palette items
  const { setNodeRef: setDroppableRef, isOver } = useDroppable({
    id: question.id,
  });

  // Combine refs
  const setNodeRef = (node: HTMLElement | null) => {
    setSortableRef(node);
    setDroppableRef(node);
  };

  // ... rest of component
}
```

const collisionDetection: CollisionDetection = (args) => {
  if (args.active.data.current?.questionType) {
    // For palette items, use pointerWithin to detect specific question cards

      // Return the first collision (the question we're over)
