# Refine Drop Indicator: Position-Aware Placement

## Context
The previous implementation added a drop indicator, but it always appears at the bottom of the list. Users need the indicator to appear **between** question cards at the position where the new question will be inserted. This provides:
- Predictable insertion position (drop at slot 2 = becomes 2nd question)
- Visual consistency between drop indicator and question card heights
- Intuitive drag-and-drop feedback

## Current State
- Drop indicator only shows at the bottom of the question list
- No position awareness - can't insert between existing questions
- Heights may not match between indicator and question cards

- `apps/web/src/components/survey-builder/index.tsx` - Track drag position, pass `overId` to canvas
- `apps/web/src/components/survey-builder/builder-canvas.tsx` - Render indicator at correct position

### 2. Render Drop Indicator Between Cards
**File: `builder-canvas.tsx`**

Create a reusable drop indicator component with matching height:

```tsx
// Drop indicator with same height as question card
function DropIndicator() {
  return (
    <motion.div
      initial={{ opacity: 0, scale: 0.95 }}
      animate={{ opacity: 1, scale: 1 }}
      exit={{ opacity: 0, scale: 0.95 }}
      transition={{ type: "spring", stiffness: 300, damping: 25 }}
    >
      <div className="rounded-lg border-2 border-violet-400 border-dashed bg-violet-50 flex items-center gap-3 p-4 min-h-[60px]">
        <div className="flex h-8 w-8 shrink-0 items-center justify-center rounded bg-violet-100">
          <Plus className="h-4 w-4 text-violet-600" />
        </div>
        <span className="font-medium text-sm text-violet-600">
          Drop to add question here
        </span>
      </div>
    </motion.div>
  );
}
```

Modify the questions list to intersperse drop indicators:

```tsx
// Calculate drop position based on overId
const dropIndex = overId
  ? safeQuestions.findIndex((q) => q.id === overId)
  : safeQuestions.length;

// Render questions with drop indicator at correct position
const items = [];
safeQuestions.forEach((question, index) => {
  // Add drop indicator before this question if dragging over it
  if (isOver && activeDragItem?.type === "palette" && index === dropIndex) {
    items.push(
      <AnimatePresence key="drop-indicator">
        <DropIndicator />
      </AnimatePresence>
    );
  }
  // Add the question card
  items.push(
    <motion.div key={question.id} ...>
      <QuestionCard ... />
    </motion.div>
  );
});

// Add indicator at end if hovering over "canvas" or last position
if (isOver && activeDragItem?.type === "palette" && dropIndex >= safeQuestions.length) {
  items.push(
    <AnimatePresence key="drop-indicator-end">
      <DropIndicator />
    </AnimatePresence>
  );
}
```
