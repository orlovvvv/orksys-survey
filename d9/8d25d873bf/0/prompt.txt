# Improve Drag-and-Drop UX: Animations, Feedback & Consistency

## Context
The basic drag-and-drop functionality works (palette → canvas creates questions), but the UX is jarring:
1. **Visual disconnect**: Dropping from palette shows the item "pull back" to original position, then a new item appears suddenly
2. **No drop animation**: DragOverlay disappears instantly without transitioning to the drop location
3. **Inconsistent reordering**: `pointerWithin` collision detection doesn't work well for sortable items within canvas (needs `closestCenter`)
4. **Missing feedback**: No visual indication during drag-over about where the item will be placed

## Root Causes
1. **Single collision detection strategy**: Using `pointerWithin` for everything breaks sortable reordering which needs `closestCenter`
2. **No drop animation**: DragOverlay unmounts immediately without animating to final position
3. **No intermediate state**: No visual preview showing where the new question will appear
4. **Framer Motion layout conflict**: Layout animations can conflict with dnd-kit transforms

## Implementation

### 1. Hybrid Collision Detection
**File: `index.tsx`**

Create a custom collision detection that uses different strategies based on drag source:

```tsx
import { pointerWithin, closestCenter, rectIntersection, CollisionDetection } from "@dnd-kit/core";

// Custom collision detection: pointerWithin for palette, closestCenter for canvas reordering
const collisionDetection: CollisionDetection = (args) => {
  // If dragging from palette (has questionType), use pointerWithin for cross-container
  if (args.active.data.current?.questionType) {
    const pointerCollisions = pointerWithin(args);
    if (pointerCollisions.length > 0) {
      return pointerCollisions;
    }
  }
  // For canvas reordering, use closestCenter for better sortable behavior
  return closestCenter(args);
};
```

Use in DndContext:
```tsx
<DndContext
  sensors={sensors}
  collisionDetection={collisionDetection}
  onDragStart={handleDragStart}
  onDragEnd={handleDragEnd}
>
```

### 2. Add Drop Animation with `dropAnimation`
**File: `index.tsx`**

Configure DragOverlay with proper drop animation:

```tsx
import { defaultDropAnimation, DragOverlay } from "@dnd-kit/core";

// Custom drop animation that fades out smoothly
const dropAnimation: typeof defaultDropAnimation = {
  ...defaultDropAnimation,
  duration: 200,
  keyframes: ({ transform }) => [
    { opacity: 1, transform: CSS.Transform.toString(transform.initial) },
    { opacity: 0, transform: CSS.Transform.toString({ ...transform.final, scale: 0.9 }) },
  ],
};

// In render:
<DragOverlay dropAnimation={dropAnimation}>
  {renderDragOverlay()}
</DragOverlay>
```
